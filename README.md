Aplicativo SaaS focado em produtividade e construção de hábitos, combinando ferramentas de rastreamento com mecânicas de gamificação para engajar o usuário.

### 🛠️ Arquitetura e Tecnologias
Este é um projeto proprietário (código-fonte fechado), desenvolvido com foco em alta performance e escalabilidade.
*   **Front-end Mobile:** Flutter (Dart) com gerenciamento de estado otimizado.
*   **Back-end & Banco de Dados:** Firebase Cloud Firestore (NoSQL em tempo real).
*   **Segurança:** Google Authentication e regras de segurança nativas do Firebase.
*   **Deploy e Distribuição:** Google Play Console.

### ⚙️ Desafios Resolvidos
*   Estruturação de um banco de dados em tempo real para sincronização instantânea das tarefas.
*   Criação de uma interface nativa fluida, aplicando conceitos de gamificação sem comprometer a performance do dispositivo.
*   Implementação de todo o fluxo de publicação oficial, desde a assinatura do app até a gestão das faixas de teste na Play Store.
